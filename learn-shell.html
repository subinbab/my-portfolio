What is Shell Scripting?

Shell scripting is a powerful way to automate tasks in Unix/Linux systems. A shell script is a text file containing a series of commands that the shell can execute.

Your First Shell Script

2. Variables and User Input

○ Not Started

Working with Variables

Variables store data that can be used throughout your script. In bash, you don't need to declare variable types.

Variable Examples

#!/bin/bash
# Variable assignment (no spaces around =)
name="John Doe"
age=25
today=$(date +%Y-%m-%d)

echo "Name: $name"
echo "Age: $age"
echo "Today is: $today"

# Reading user input
echo "What's your favorite color?"
read color
echo "Your favorite color is: $color"

3. Control Structures

○ Not Started

If Statements and Loops

Control structures allow you to make decisions and repeat actions in your scripts.

If Statements and Loops

#!/bin/bash
# If statement
echo "Enter a number:"
read number

if [ $number -gt 10 ]; then
    echo "Number is greater than 10"
elif [ $number -eq 10 ]; then
    echo "Number is exactly 10"
else
    echo "Number is less than 10"
fi

# For loop
echo "Counting from 1 to 5:"
for i in {1..5}; do
    echo "Count: $i"
done

# While loop
echo "Countdown:"
count=3
while [ $count -gt 0 ]; do
    echo "$count..."
    count=$((count - 1))
done
echo "Done!"

4. Functions and File Operations

○ Not Started

Creating Reusable Functions

Functions help you organize code and avoid repetition. You can also work with files and directories.

Functions and File Operations

#!/bin/bash
# Function definition
greet() {
    local name=$1
    echo "Hello, $name! Welcome to shell scripting."
}

# Function with return value
add_numbers() {
    local num1=$1
    local num2=$2
    local result=$((num1 + num2))
    echo $result
}

# Using functions
greet "Alice"
result=$(add_numbers 15 25)
echo "15 + 25 = $result"

# File operations
echo "Creating a test file..."
echo "This is a test file" > test.txt
echo "File contents:"
cat test.txt

# Check if file exists
if [ -f "test.txt" ]; then
    echo "test.txt exists!"
    echo "File size: $(wc -c < test.txt) bytes"
fi

Additional Resources

Cheat Sheet

  • $0 - Script name
  • $1, $2... - Script arguments
  • $# - Number of arguments
  • $? - Last command exit status
  • $$ - Process ID

Common Commands

  • ls - List files
  • cd - Change directory
  • pwd - Print working directory
  • grep - Search text
  • find - Find files

Best Practices

  • Always use #!/bin/bash
  • Quote variables: "$var"
  • Use meaningful variable names
  • Add comments to explain complex logic
  • Check exit codes for error handling
